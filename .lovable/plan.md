# Rural Impact Landing Page

## Goal
Build the screenshot-inspired landing page as a polished, responsive one-page experience, preserving its green-and-orange visual language, section order, editorial rhythm, and interactive storytelling.

## What I’ll build
- A compact branded navigation bar with desktop links, a clear contact action, and a mobile menu.
- A full-width rural landscape opening with dark overlay, supplied headline, supporting text, and one call to action.
- Three illustrated pillars for Research, Communication, and Capacity/Action.
- An impact statement with animated counters for 13+ years, 100+ projects, and 10+ states.
- An interactive sector explorer with six tabs and smoothly changing illustrated previews.
- A green field-story spotlight with image, quote, and action.
- Four interactive initiative and case-study cards with badges, author details, and video-play hover treatments.
- A community photo band paired with a strong orange statement panel.
- An Insights & Knowledge Hub with report previews and links.
- A comprehensive newsletter and sitemap footer with social links.

## Visual and interaction approach
- Use generated rural, fieldwork, community, and report imagery matching the reference rather than embedding the screenshot itself.
- Define a semantic palette of lush greens, warm orange, soft off-white, ink, and muted neutrals.
- Use a clean humanist sans-serif with strong editorial sizing and compact rounded controls.
- Add restrained scroll reveals, animated number counters, card lift/tilt, smooth tab transitions, and reduced-motion fallbacks.
- Keep all interactions keyboard accessible and all layouts usable from phone through wide desktop.

## Technical details
- Implement the page at `/` with small reusable React sections and local data collections.
- Use the existing TanStack Router foundation; add Motion for React for the requested Framer Motion behavior.
- Update route-specific page metadata and shared font loading.
- Generate and import optimized visual assets through the project asset flow.
- Verify the final page in a live browser at desktop and mobile sizes, including tab switching, menu behavior, counter animation, links, and newsletter form feedback.
